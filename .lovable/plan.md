## Партнёрская программа — Telegram-бот + Админ-панель

### Шаг 1: Подключение Supabase

Подключим Supabase (или Lovable Cloud) для базы данных и Edge Functions.

### Шаг 2: База данных

Создадим таблицы:

- **partners** — id, name, telegram_id, username, ref_code, traffic_source, created_at
- **clicks** — id, ref_code, timestamp, ip
- **leads** — id, ref_code, name, telegram, contact, status, created_at
- **payouts** — id, partner_id, amount, status, created_at

### Шаг 3: Telegram-бот (Edge Function)

Edge Function `telegram-bot` как webhook для Telegram Bot API:

- **/start** — стартовый экран с inline-кнопками (Стать партнёром, Как это работает, Материалы, Моя статистика)
- **Регистрация** — пошаговый сбор данных (имя, username, источник трафика), генерация ref_code
- **Партнёрская ссылка** — выдача ссылки `https://PetrFirstovBot/?ref=ref_XXXX`
- **Статистика** — показ переходов, лидов, клиентов, дохода
- **Материалы** — описание услуг, кейсы, тексты для рекомендаций
- **Уведомления админу** — при новом лиде отправка сообщения админу

### Шаг 4: Edge Function для трекинга кликов

Отдельная Edge Function `track-click` — вызывается с сайта при переходе по реферальной ссылке, записывает клик в базу.

### Шаг 5: Edge Function для записи лидов

Edge Function `create-lead` — вызывается при отправке заявки на сайте, записывает лид и уведомляет админа через бот.

### Шаг 6: Админ-панель (веб-интерфейс)

- **Дашборд** — общая статистика (партнёры, клики, лиды, конверсия)
- **Список партнёров** — таблица с фильтрами, ref_code, источник трафика
- **Лиды** — список лидов с привязкой к партнёру, статус (новый/в работе/клиент)
- **Выплаты** — управление выплатами партнёрам, изменение статусов
- **Авторизация** — вход по email/паролю для администратора

### Шаг 7: Настройка Telegram Webhook

Инструкция по созданию бота через @BotFather и установке webhook на Edge Function.

### Что потребуется от вас:

1. Подключить Supabase/Lovable Cloud к проекту
2. Создать Telegram-бота через @BotFather и предоставить токен
3. Указать Telegram ID админа для уведомлений
